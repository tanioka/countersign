# pi_gpio — GPIO の実機照合(Raspberry Pi 4、17 番と 27 番をジャンパでつなぐ)

つなぎ方: **GPIO17(11 番ピン)と GPIO27(13 番ピン)を、線 1 本でつなぐ**(LED も抵抗も要らない。ほかのピンには何もつながない)。

1. このフォルダを Pi に丸ごと置く(`bin/` は AArch64 の静的 ELF。ビルド済み)。
2. `python3 run_on_pi.py`(`gpio` グループのユーザー。`groups` に gpio があること)。
3. `report.txt` ができる。それを返してほしい。

| プログラム | 見ること | 期待 |
| --- | --- | --- |
| g_17to27 | 17 を出力(1,0,1,0)、27 を入力で読む | 1010 |
| g_27to17 | 27 を出力、17 を入力(逆向き) | 1010 |
| g_pull | 両方入力にして、27 をプルアップ → プルダウン | 10 |
| g_count | 17 を 200 回変え、27 が毎回同じ値か | 200 |

期待は疑似カーネル(`make_expected.py` が、17-27 をつないだ線を模して作った)の予想。つなぎ忘れると g_17to27 は 0000 などになる。
LED の点滅(`led_gpio.sn`)は別。LED をつなげるなら 17 番 ── 330Ω ── LED ── GND で、ここの線は外す。
