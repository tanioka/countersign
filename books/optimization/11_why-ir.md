# 第11章 なぜ中間表現を置くか

## 継ぎはぎをやめて、共通の足場を置く

このプロジェクトの旧来の構文木は、既定の読みと `--strict` の読みの両方のために作られている。`--strict` の答えを機械語に合わせるには、機械語側の補正(`strict_rewrite` の 6 つ、第13章)を継ぎ足していた(`sign_sir.py` の先頭の記述)。

**SIR(中間表現)は、`--strict` の読みを木の形そのものに書き出したもの**で、評価器とコード生成が同じ物を見る。節の種類は整数・空(`void`)・仮引数・四則と符号反転・比べ・比べの連鎖・`&`と`|`・行の列・呼び出し・並び・リスト・添字・長さ・畳みである。規則の例をいくつか挿げる(ツールの説明を要約)。

| 節 | 意味 |
| --- | --- |
| `op` | `+ - * / %`。void の被演算子は単位で消える(`5 + _` は 5)。`/` `%` は割る数が 0 なら void |
| `rows` | 行の列。条件が void でなく値も void でなければその値。値が void なら次の行へ落ちる(V10) |
| `call` | 口の数ちょうどの呼び。実引数が 1 つでも void なら呼びは成り立たず、評価は部分適用を返す |
| `flow` | 並び。void の項は消え、項が 1 つだけ残ればその項、0 なら void |

整数は 64 ビットで、範囲を出れば `!_` になる。下限は -MAX(MIN に着いても `!_`、value\_spec V5)とする。

SIR に下げられない形は `Unsup` を投げて**理由を持って断る**。断りの理由を数えると、それがそのまま次の作業の一覧になる。扱いにくい形を「とりあえず通す」のではなく「名前を付けて断る」設計にしたことがこの章のポイントである。

## `--via-sir` で経路を切り替えて比べる

`python3 sign.py --asm --strict --via-sir` は、`--strict` の道を旧経路(`strict_rewrite`)ではなく SIR から木を作って出す旁路である。このコンテナで実行した結果を示す。

| 入力 | `--via-sir` での結果 |
| --- | --- |
| `f : x y ?`(行: `x > y : x / y`、`x + 1`)と `f 3 4` | 「SIR 経由で出します」。出力は 52 行(旧経路は 53 行、内容は違う) |
| 文字列 `` `hi` `` を返す定義 | 「SIR に下げられないので旧経路で出します(整数でない字面)」 |

経路の選び方が stderr に必ず出ることも設計の一部で、「どちを通ったか」を利用者が見える。

突き合わせは次のとおりである(このコンテナで実行)。

- `diff_observe.py`(見本表の照合): 終了コード 0。後段(SIR = 機械語)は一致 161、機械語が罠 11(溢れ・部分適用)。SIR 経由の機械語も一致 161・罠 11。SIR に下げられない形の上位は「比べの連鎖の形(R119)」3、「行の値が部分適用」2。
- `fuzz_sir.py 800 7`(評価器と SIR の乱数照合): 一致 800、食い違い 0。

機械語側の「罠」を許している点に注意。この照合は「違う答えを出したときだけ誤答」と数える。罠や断りは第25章で見た別項目である。

## 仕様由来、実装の選択、限界

**仕様由来。** SIR が表す意味(void の扱い、行の落ち方 V10、整数の範囲 V5 など)は、仕様の規則を木の形にしたものである(ツールの記述で規則番号を引いている)。

**実装の選択。** SIR を置くことそのもの、節の種類の選び方、`Unsup` で断ること、`--via-sir` を旁路にすること。

**照合の道具を疑う。** 実装ノートに、`run_asm` の戻りの形を取り違えて、機械語の答えを全部「断り」と数えていた時期があると記録されている。その間の「誤答 0」は何も示していなかった。照合の結果は一致と断りの内訳といっしょに読むべきで、第25章の分類を分けて数える理由の一つになっている。

**限界。**

- 文字列・器・範囲・展開(`~`)・節の値は SIR の外で、旧経路で出る(実装ノート)。ここは評価器と機械語を `test_asm_strict.py` が直接突き合わせる。
- `--via-sir` を既定の経路にするかは未決で、旁路のままである(第29章)。実装ノートは、SIR 経由の一致は旧経路と同じかそれ以上と記録している。
- ここで再実行したのは `diff_observe.py` と `fuzz_sir.py 800 7` の 2 つで、`test_sir.py` の他の乱数試験(リスト・流れ・旁路)はここでは回していない。
