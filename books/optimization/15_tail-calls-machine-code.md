# 第15章 末尾呼び出しを機械語へ

末尾呼び出しの除去は、「深い再帰で OS のスタックが尽きる」という観測の違いを消す最適化で、実機の試験で範囲を広げた。

## なぜ末尾呼び出しか

繰り返しを再帰で書く Sign では、繰り返しの回数がそのまま呼び出しの深さになる。末尾呼び出しを跳び命令にしないと、深さが OS のスタックを超えてシグナル(終了コード 139)で落ちる。評価器は同じプログラムの答えを出すので、これは観測の差になる。

だから末尾呼び出しの除去は「速くする」より前に「落ちなくする」最適化として効く。この章では、除去する形を三段で広げた経緯と、広げるときの条件を示す。深い非末尾再帰(100 万や 1 億回)が落ちるのは、今も仕様の外として許容している。

## 三段の広げ方

1. **自己末尾**: 関数が自分を最後に呼ぶ形を、実引数を入れ直して関数の先頭へ跳ぶ(`b` で自分へ)。最初からあった。
2. **枝の中の末尾**: strict の行の連なりは `(c & v) | 次` に書き換わる(第13章)。この v と、`|` `&` の右は関数の最後の仕事なので、ここでの呼び出しも末尾にする(`gen_bin_tail`)。
3. **兄弟関数への末尾**: 別の関数を最後に呼ぶ形。自分のフレームを戻してから呼び先へ `b` で飛ぶ。戻り先は自分の呼び元のままなので、呼び出しが積み上がらない。相互の末尾再帰もこれで一定のスタックで回る。

三つ目は、まだ入れていなかった段階では「相互の末尾呼び出しなどは普通の `bl` で再帰する(積み上がる)」と実装ノートに記していた。設計者の参照コンパイラにある相互末尾呼び出しの畳み込みは、この実装では入れていない(広げ方は畳み込みではなく、跳びである)。

## 兄弟への末尾呼び出しの条件

飛びにできるのは、`sign_asm.py` の `gen_call_core` が次をすべて満たすところだけで、満たさなければ普通の `bl` で呼ぶ(安全側に倒す)。

| 条件 | 見ているもの | なぜ必要か |
| --- | --- | --- |
| 末尾の位置で、呼び先が自分ではない | `tail`、`f != self.name` | 自己末尾は別の道で処理済み |
| 実引数がすべて Int 、1 レジスタで渡る | `kd == "I"` と 1 要素の一時変数 | 器(リスト・文字列)は自分のフレームにあるので、フレームを戻すと指す先が無くなるからと考えられる |
| 実引数が 8 個以下 | `len(tmps) <= len(ARG_REGS)` | レジスタだけで渡せる。スタックで渡す引数はフレームを戻すと壊れる |
| 戻り値が Int | `rk == "I"` | 器を返すときの `sret` の置き場が自分のフレームにありうる |
| 自分が `sret`、`alloca` を持たない | `not self.sret`、`not self.alloca` | 自分のフレームの領域を呼び先が使うかもしれない |
| 呼び先の仮引数がすべて Int、伸ばす関数(`grow`)ではない | `pkind[f]`、`bound`、`grow` | 呼び先のやり方を増やさない。並列やマスクの経路とも重ならない |

「なぜ必要か」の列は、コードの条件から推測した理由で、コードのコメントに書かれたものではない。条件を緩めるときは、緩めた形を三者一致テスト(第24章)に足して確かめる。

## 実機で見つけ、直し、再確認した経緯

除去の範囲は、実機(Raspberry Pi 4)の第三段の試験で狭いと分かった。実機の OS のスタックは有限なので、深い再帰では落ちる。

- **直す前**: 単純な自己末尾呼びは 1 億回でも一定のスタックで正しい値。枝(条件)の中の末尾呼び 100 万回と、相互の末尾呼び 100 万回以上は SIGSEGV(終了コード 139)。誤答ではないが、評価器と観測が分かれる。
- **直した内容**: `|` `&` の右と `(c & v) | 次` の v、および兄弟関数への末尾呼び(実引数が全部 Int、器の置き場なし)を、フレームを戻して `b` で飛ぶ形にした。
- **再実行(2026-11-22)**: 69 件中一致 67、異常終了 2、誤答 0。末尾再帰の 11 件はすべて一致し、相互の 1 億回も一定のスタックで回った。残る 2 件は深い非末尾再帰(100 万・1 億回)で、末尾ではないので除去できず、仕様の外として許容している。

この経緯は、最適化を「実機と同じ観測をするため」として測ると、エミュレータだけでは見えない穴が見つかることを示す例でもある。第5章の「測定の落とし穴」と対になる。
