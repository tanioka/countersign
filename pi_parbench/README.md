# pi_parbench — --par の時間を複数回測る(Raspberry Pi 4)
`python3 run_on_pi.py`(既定 5 回。回数は引数で `python3 run_on_pi.py 7`)。7 プログラム × 4 変種 × 5 周 = 140 回で、5〜10 分ほどかかる。できた `report.txt` を返してください。
- 変種を交互に回すので、温度や他の処理のぶれが 1 つの変種に偏らない。中央値と最小〜最大を出す。
- 他の処理を止めて(ブラウザなど)、できれば冷えた状態で。`governor` が performance でなくても動くが、記録に残る。
- 答えは毎回照合する(食い違えば report に出る)。
