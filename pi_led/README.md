# pi_led — LED の実機確認(Raspberry Pi 4)

つなぎ方: GPIO17(11 番ピン)── 330Ω ── LED の長い足(+)、短い足(−)── GND(9 番ピン)。**17-27 のジャンパは外す**。

1. `bin/led_blink5`: 500 ms ごとに 5 回点滅して終わる(画面に `0` が出て終了。終わると消灯)。
   `./bin/led_blink5` ── 点滅の回数と間隔(だいたい 1 秒に 1 回)を見る。
2. `bin/led_gpio`: ゲーム機の駆動部つきの `led_gpio.sn`(アラームで 500 ms ごとに反転、止めるのは Ctrl+C)。`./bin/led_gpio` ── 1 秒周期で点滅し続けるか。

どちらも `gpio` グループのユーザーで(sudo 不要)。うまく動かないときは `./bin/led_blink5; echo rc=$?` の出力と、LED の向き(長い足が + 側)を教えてください。
